- (decision) Initiate web research to find community-discovered Xbox Game Pass catalog API endpoints, matching the 'technical' research type
- (source) DuckDuckGo search results for: xbox game pass catalog api endpoint github
- (source) NikkelM/Game-Pass-API github repository readme - indicates use of a public XBOX catalog API
- (claim) The public undocumented API to fetch Game Pass catalog IDs uses catalog.gamepass.com. Source: https://github.com/NikkelM/Game-Pass-API/blob/main/js/gamePass.js (Accessed Aug 26 2026)
- (claim) The endpoint for Xbox Game Pass console is: https://catalog.gamepass.com/sigls/v2?id=f6f1f99f-9b49-4ccd-b3bf-4d9767a77f5e. Source: https://github.com/NikkelM/Game-Pass-API/blob/main/js/gamePass.js (Accessed Aug 26 2026)
- (claim) The endpoint for Xbox Game Pass PC is: https://catalog.gamepass.com/sigls/v2?id=fdd9e2a7-0fee-49f6-ad69-4354098401ff. Source: https://github.com/NikkelM/Game-Pass-API/blob/main/js/gamePass.js (Accessed Aug 26 2026)
- (claim) The endpoint for EA Play is: https://catalog.gamepass.com/sigls/v2?id=b8900d09-a491-44cc-916e-32b5acae621b. Source: https://github.com/NikkelM/Game-Pass-API/blob/main/js/gamePass.js (Accessed Aug 26 2026)
- (claim) To fetch full details for a batch of game IDs, the display catalog API is used: https://displaycatalog.mp.microsoft.com/v7.0/products?bigIds={batch}&market={market}&languages={language}. Source: https://github.com/NikkelM/Game-Pass-API/blob/main/js/gamePass.js (Accessed Aug 26 2026)
- (event) Research complete. Discovered undocumented endpoints via NikkelM/Game-Pass-API github repository.
